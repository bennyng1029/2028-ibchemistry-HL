# Structure Lab 한국어 용어집 (English → 한국어)

Structure Lab(IB Chemistry, Structure 1·2·3, first assessment 2025)을 한국어로 옮길 때 따르는 **용어 기준**입니다.
여기 없는 용어를 쓸 때는 먼저 이 표에 추가하세요. 영어 용어 하나에는 번역어 하나를 씁니다.

- 독자: 16세 학생. 시험은 영어로 보고, 설명은 한국어로 읽을 수 있습니다.
- 우선순위: **정확성 → 이해하기 쉬움 → 한국 고등학교 화학 표준 용어 → IB 관례 유지**.
- 용어 근거: 2015·2022 개정 교육과정 고등학교 「화학 Ⅰ」「화학 Ⅱ」 교과서, 대한화학회 「화학술어집」과
  원소·화합물 명명법(2014년 이후 권고안). 교과서와 대한화학회 표기가 다르면 교과서를 따르고 메모를 답니다.
- 작업 방법과 HTML 규칙은 [TRANSLATING.md](TRANSLATING.md)를 보세요.

## 1. 문체 안내

### 1.1 말투

- **해요체**(…해요, …예요, …이에요, …할 수 있어요)를 씁니다. 친절한 과외 선생님 말투입니다.
  설명문 속 정의나 표, 버튼 같은 짧은 라벨은 명사형으로 끝냅니다(「정답 확인」, 「다음 문제」).
- 문장은 짧게, 한 문장에 한 가지만. 영어 어순을 따라가지 말고 자연스러운 한국어로 씁니다.
- 쉬운 말을 씁니다. 「~을 수행하다」보다 「~하다」, 「~하는 것이 가능하다」보다 「~할 수 있다」.
- 권유는 「~해 봐요」, 「~하세요」. 명령형 「~하시오」는 지시어(command term) 번역에만 씁니다(§3).
- 강조는 `<strong>`. 기울임꼴은 쓰지 않습니다(변수 `<i>n</i>`, `<i>V</i>`는 그대로).
- 느낌표는 아껴 씁니다. 칭찬은 짧게(「좋아요.」, 「잘했어요.」).

### 1.2 "you", "we"

- "you"는 대부분 **옮기지 않습니다**(주어 생략). "You need to know …" → 「…를 알아 두세요」.
- 꼭 필요하면 「여러분」. "your answer" → 「내 답」 또는 「답」. "your teacher" → 「선생님」.
- "we"(저자)는 옮기지 않거나 「이 사이트에서는」으로 씁니다.

### 1.3 숫자·단위·식

- 숫자, 단위, 화학식, 변수는 영어와 똑같이 씁니다. 숫자와 단위 사이는 한 칸 띄웁니다(`25.0 cm³`, `298 K`).
- 단위는 **IB 표기를 바꾸지 않습니다**: `dm³`(L로 바꾸지 않음), `cm³`(mL로 바꾸지 않음), `mol dm⁻³`(M으로 바꾸지 않음),
  `g mol⁻¹`, `kJ mol⁻¹`, `kPa`. 처음 나오는 곳에서 한 번 「1 dm³ = 1 L」라고 덧붙여도 됩니다.
- 수량은 아라비아 숫자로 씁니다(「2개」, 「3가지」, 「4단계」). 숫자를 한글로 풀어 쓰지 않습니다
  (검사기가 영어의 숫자가 번역에도 있는지 확인합니다). 다만 영어에서 숫자를 단어로 쓴 경우("two O atoms")는
  「두 O 원자」, 「O 원자 두 개」처럼 한글로 써도 됩니다. 계산 줄(`.worked__math`)에는 영어에 없는 숫자를 넣지 마세요.
- 유효 숫자: "3 s.f." → 「유효 숫자 3자리」. "2 decimal places" → 「소수점 아래 2자리」.
- 표의 머리글은 IB 방식 「양 / 단위」(`부피 / cm³`)를 그대로 씁니다.

### 1.4 화학 이름

- 화합물 이름은 대한화학회 명명법의 한국어 이름을 씁니다: 염화 나트륨, 황산 구리(II), 수산화 칼슘, 산화 철(III).
  (교과서처럼 띄어 씁니다: 「염화 나트륨」, 「탄산 칼슘」.)
- 산화수 로마 숫자는 반각 괄호와 대문자: `철(III)`, `구리(II)`.
- 원소 이름은 §9 표를 따릅니다. Na는 「나트륨」, K는 「칼륨」(교과서 표기). 영어 이름(sodium, potassium)과
  모양이 많이 다르므로 처음 나올 때 원소 기호를 함께 씁니다.
- **유기 화합물은 IUPAC 영어 이름을 그대로 둡니다**(시험은 영어 이름을 요구합니다): ethanol, propan-2-ol,
  but-2-ene. 필요하면 한 번만 괄호로 한국어 이름을 덧붙입니다: 「ethanol(에탄올)」. 작용기·동족 계열의 일반 이름
  (알코올, 알데하이드, 카복실산 …)은 한국어로 씁니다.

### 1.5 문장 부호

- 한국어는 **반각** 문장 부호를 씁니다: 마침표 `.`, 쉼표 `,`, 쌍점 `:`, 괄호 `( )`, 물음표 `?`. 전각 부호(。、：（）)는 쓰지 않습니다.
- 인용과 용어 강조에는 작은따옴표 ‘ ’ 또는 큰따옴표 “ ”를 씁니다. 「 」는 이 용어집의 설명에만 씁니다.
- 띄어쓰기는 한글 맞춤법을 따릅니다. 화학식 뒤의 조사는 붙여 씁니다(「H₂O는」, 「NaCl을」). 조사는 화학식을
  읽는 소리에 맞춥니다: `H2O`(에이치투오)는/를, `CO2`(시오투)는/를, `NaCl`(엔에이시엘)은/을, `O2`(오투)는/를.
  애매하면 「H₂O 분자는」처럼 명사를 넣어 피합니다.

### 1.6 영어를 함께 보여 줄 때 (시험은 영어)

- `<dfn>`의 핵심 용어는 처음 정의할 때 「번역어 <span class="en-term">(English term)</span>」로 씁니다:
  `<dfn>몰 <span class="en-term">(mole)</span></dfn>`.
- 지시어는 문제의 줄기(stem)에서 처음 중요할 때 「설명하시오 (explain)」처럼 영어를 덧붙입니다.
- 시험 팁(`callout--exam`), 모범 답안, 채점 기준은 사이트가 영어를 위에, 번역을 아래에 보여 줍니다. 번역만 하면 됩니다.

### 1.7 IB와 한국 교육과정이 다른 곳 (IB를 따르고 짧은 메모를 답니다)

| 주제 | IB (이 사이트) | 한국 교과서 | 처리 |
|---|---|---|---|
| 표준 상태 기체 부피 | STP 273 K, 100 kPa, 22.7 dm³ mol⁻¹ | 0 °C, 1 atm, 22.4 L | IB 값 그대로. 필요한 곳에만 한 줄 설명 |
| 농도 단위 | mol dm⁻³ | M (mol/L) | IB 단위 그대로 |
| 산화 상태 | oxidation state | 산화수 | 「산화수」 사용 |
| 원자 반지름 등 자료 | data booklet | — | 「데이터 부클릿」 |
| Additional HL | AHL | — | 「AHL(HL 추가 내용)」, 짧게는 「HL 추가」 |
| 유기 화합물 이름 | IUPAC 영어 | 한국어 이름 | 영어 그대로(§1.4) |

### 1.8 피할 것

- 번역투(「~에 의해」, 「~를 가지다」의 남용, 「그것은」), 지나친 한자어.
- 같은 용어를 페이지마다 다르게 옮기기.
- 영어 키나 `// EN:` 주석 고치기.
